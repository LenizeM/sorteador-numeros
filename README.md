# 🎲 Sorteador de Números

Projeto desenvolvido para praticar **lógica de programação em JavaScript**, com foco em variáveis, condicionais, estruturas de repetição e manipulação do DOM.  
A aplicação permite sortear uma quantidade de números dentro de um intervalo definido pelo usuário.

## 📚 Aprendizados

Durante o desenvolvimento, foram praticados os seguintes conceitos:

- Análise da estrutura de um código **HTML** para planejar funcionalidades  
- Declaração e uso de **variáveis** em JavaScript  
- Recuperação de elementos da página com **document.getElementById()**  
- Captura de valores digitados em campos de formulário usando **.value**  
- Uso de **Template Strings** para concatenar variáveis em strings  
- Conversão de valores com **parseInt** (String → Número inteiro)  
- Estruturas de repetição com **for** para gerar números aleatórios  
- Criação e manipulação de **arrays** (incluindo uso de `push`)  
- Utilização de funções de terceiros para gerar números aleatórios em intervalos  
- Implementação de condicionais **if/else** para controlar funcionalidades  
- Manipulação de classes CSS via **classList.add()**, **classList.remove()**, **classList.contains()**  
- Atualização dinâmica do conteúdo da página com **innerHTML**

## 🚀 Funcionalidades

- Inserir a quantidade de números a serem sorteados  
- Definir o intervalo inicial e final do sorteio  
- Exibir números sorteados de forma dinâmica  
- **Botão Sortear** → gera os números conforme os parâmetros definidos  
- **Botão Reiniciar** → limpa os campos e prepara para um novo sorteio
